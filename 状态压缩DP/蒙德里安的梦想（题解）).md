## 题解（蒙德里安的梦想）

### 1 问题重述
题目要求我们编写算法完成画家蒙德里安的梦想，即使用$1 \times 2$的日字格填满$N \times M$的棋盘。

### 2 题目简化

我们可以从题目要求中看出：使用日子格装填棋盘只能横向装填或纵向装填。
如果我们只考虑横向装填的方式，再通过判断计算出所有能够刚好空出所有纵向日字格且装填纵向日字格后棋盘刚好装满的横向装填方式。而这些横向装填方案刚好等于总方案数。问题则被简化为求这些特殊条件下的横向装填方案数。

### 3 考虑状态压缩

因为棋盘为$N \times M$的形式，即**N**行**M**列，且我们在考虑横向装填时必须要考虑每一行于每一列的装填方案。基于以上考虑，可以使用二进制的表示方式来表达每一列的装填状态，通过**0**/**1**表示这一列是否横向装填，每一列通过一串由**0**/**1**组合形成的数字来表示，通过这种方法将状态表示压缩成二进制的形式。
### 4 状态转移数组
$f[i][j]$表示前$i-1$列已经装填好且第$i-1$列向第$\,i\,$列按照$\,j\,$的形式横向装填的总方案数。

**注：因为$\,j\,$的值是一个十进制数，$\, j \,$的形式则是指此十进制数对应的二进制数，此二进制数**0**与**1**对应的行数则是其表示形式，**1**则表示横向装填，** **0** **表示不装填**

### 5 状态转移方程

#### 5.1 递归基

$$
f[0][0]=1
$$


表示第**0**列向第一列没有一个行进行横向装填的总方案数，因为这种方式只有这一种，即等于**1**。

#### 5.2 横向装填规则

1. 因为装填的时日字格，又需要遍历每一列，所以在横向装填时要避免装填时第$i-1$列日字格的后一格与第i列日字格的前一格重合。代码解决这个问题只需要将第$i-1$列的$\,j\,$与第$\,i\,$列的$\,j\,$进行**&**运算即可，若结果为**1**，说明重合，不能装填。
2. 因为我们只考虑了横向装填，那么一定要留出合适的位置给纵向装填的日字格，即纵向行数之间的间距必须为偶数，奇数则会出现一个口字格，无法装填。这一判断主要是解决行数为奇数的问题。代码解决这个问题只需要创建一个状态数组st即可，对每一列进行判断，若出现了奇数个**0**，则说明不能装填，令$st[i]=false$。
#### 5.3 状态转移方程
在同时满足以上条件时，即可对方案数进行累加，递推得到最终的答案。
$$
f[i][j]+=f[i-1][k](k表示第i-1列的状态j)
$$

### 6 结果表示

因为$f[i][j]$表示前$i-1$列已经装填好且第$i-1$列向第$\,i\,$列按照$\,j\,$的形式横向装填的总方案数。所以最后的答案应为$f[m][0]$,$f[m][0]$表示棋盘前$\,m\,$列已经排列好，且第$\,m\,$列向$m+1$列没有横向装填，即已经刚好将整个棋盘装填完毕。

**注：因为数组是从**0**开始装填的（节省空间），但是棋盘有$\,m\,$列，而这个$\,m\,$是从**1**开始计算的，所以$f[m][0]$中的$\,m\,$是指数组中前$m-1$列已经装填好$\cdots$，也指棋盘的前**m**列已经装填好$\cdots$。**

### 7 时间复杂度
$\quad$$\,dp\,$问题的时间复杂度=状态表示 $\times$ 状态转移
#### 7.1 状态表示
1. 第一维$\,i\,$最多可取11;
2. 第二维$\,j\,$最多可取$2^{11}$;
#### 7.2 状态转移 
$\,k\,$最多可取$2^{11}$

计算总和得：
$$
11 \times 2^{11} \times 2^{11} \approx 4 \times 10^{7}
$$
因为总时间要求小于**1.5**秒，最多可计算$1.5 \times 10^{9}$（C++编译器每秒能够计算大约$10^{9}$次整数加法运算），因此时间复杂度符合题目要求。

## 源代码

```c++
#define _CRT_SECURE_NO_WARNINGS
#include <iostream>
#include <algorithm>
#include <cstring>

using namespace std;

const int N = 12, M = 1 << N;//数据范围

int n, m;//行数与列数
long long  f[N][M];//状态转移数组
bool st[M];//状态数组

int main()
{
	cin.tie(nullptr);
	ios::sync_with_stdio(false);//输入输出优化

	while (cin >> n >> m, n)//达到当最后一行为0时，停止输入，不做运算的目的
	{
		//处理状态数组st，处理出横向放置时的特判条件
		for (int i = 0; i < 1 << n; i++)
		{
			int cnt = 0;
			st[i] = true;

			for (int j = 0; j < n; j++)
				if (i >> j & 1)//如果为1，说明到了一个新的1，判断两个1之间0的个数
				{
					if (cnt & 1) st[i] = false;//如果个数为奇数，st状态赋值为false
					cnt = 0;//重置cnt为偶数
				}
				else cnt++;//如果为0，则自增，计算0的个数
			if (cnt & 1) st[i] = false;//判断最后一段种0的个数
		}

		memset(f, 0, sizeof f);//初始化f数组为0
		f[0][0] = 1;//递归基
		for (int i = 1; i <= m; i++)
			for (int j = 0; j < 1 << n; j++)
				for (int k = 0; k < 1 << n; k++)
					if ((j & k) == 0 && st[j | k])//满足特判条件则横向装填
						f[i][j] += f[i - 1][k];//累加所有的情况

		cout << f[m][0] << endl;//输出答案
	}

	return 0;
}
```
