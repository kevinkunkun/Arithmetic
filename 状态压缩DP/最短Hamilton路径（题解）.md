## 题解（最短Hamilton路径）

### 1 问题重述
要求在给出顶点数为$n$($1 \leq n \leq 20$)，同时给出每两个点之间的距离的途中，实现哈密顿回路。即从第**0**个点走到第$n-1$个点，要求不重不漏的走完所有点，且距离最小。

### 2 状态压缩

将最多**20**个点的图压缩为以**0**/**1**表示的一串数字，**0**表示没有经过此点，**1**表示经过此点。
### 3 递归基
$$
f[1][0]=0
$$

表示从第0个点走到第0个点共经历了第0个点，距离为0。

### 4 状态转移数组

$f[i][j]$表示从第**0**个到第$\,j\,$个点的路径中经过了以二进制表示的$\,i\,$中的哪些点（**1**为走过了，**0**为未走过）的路径长度和。

### 5 状态转移方程

$$
f[i][j]=f[i-(1<<j)][k]+w[j][k]
$$

**注：**

1. **$f[i][j]$可以从第**0**个点到第$\,k\,$个点的路径中经过了以二进制表示的$\,i\,$中的哪些点的路径长度和再加上已经确定的$w[j][k]$转移得到。**
2. **$w[i][j]$中存储了从$\,i\,$到$\,j\,$的路径长度。**

### 6 结果表示

结果可以表示为：
$$
f[(1<<n)-1][n-1]
$$
其中$(i<<n)-1$可以产生一个$\,n\,$位**1**的二进制数，表示每一个点都被经过，$n-1$表示已经从第**0**个点走到了第$n-1$个点。

## 源代码（含注释）

```c++
#define _CRT_SECURE_NO_WARNINGS
#include <iostream>
#include <algorithm>
#include <cstring>

using namespace std;

const int N = 20, M = 1 << N;//数据范围

int n;//顶点数
int f[M][N];//状态转移数组
int w[N][N];//距离权值数组

int main()
{
	cin.tie(nullptr);
	ios::sync_with_stdio(false);//输入输出优化

	cin >> n;//录入顶点数

	//录入距离权值
	for (int i = 0; i < n; i++)
		for (int ij = 0; j < n; j++)
			cin >> w[i][j];

	memset(f, 0x3f, sizeof f);//初始化f数组为无穷大，因为是求最小值，需要使用min函数，起始值需要为无穷大

	f[1][0] = 0;//递归基
	for (int i = 0; i < 1 << n; i++)
		for (int j = 0; j < n; j++)
			if (i >> j & 1)//寻找起点
				for (int k = 0; k < n; k++)
					if (i >> k & 1)//寻找终点
						f[i][j] = min(f[i][j], f[i - (1 << j)][k] + w[k][j]);//两点已确定，说明可以进行状态转移

	cout << f[(1 << n) - 1][n - 1] << ' ';//输出答案

	return 0;
}
```
