# 扩展欧几里得算法题解：

## 一、欧几里得算法

首先我们应该了解欧几里得算法（即辗转相除法），它可以计算出两个数的最大公约数**d**，具体公式如下：
$$gcd(a,b)=d$$
辗转相除法利用的定理如下：
$$gcd(a,b)=gcd(b,a\%b)$$

## 二、贝祖定理

接着我们引入贝祖定理：若**a**,**b**是整数,且$gcd(a,b)=d$，那么对于任意的整数**x**,**y**,$ax+by$都一定是**d**的倍数，特别地，一定存在整数**x**,**y**，使$ax+by=d$成立。
贝祖定理的公式如下：
$$ax+by=gcd(a,b)$$

## 三、推广欧几里得算法

通过以上两个定理，我们就可以对欧几里得算法进行推广，可以在进行辗转相除时，同时通过贝祖定理计算x与y的值，即可求得这个方程的一组正整数特解。
我们通过数学推导得到了最后一组**x**与**y**的解为1和0。即当$b=0$时，也就是辗转相除法的最后一步时，此时$gcd(a,0)=a$，所以$ax+0=a$,即$x=1$。有了这一组解，我们可以通过辗转相除法的等式$[gcd(a,b)=gcd(b,a\%b)]$和贝祖定理$[ax+by=gcd(a,b)]$,联立得到递推式：
$$\begin{cases}x1=y2 \\ y1=x2-\lfloor  \frac{a}{b} \rfloor \times y2 \end{cases}$$
通过以上递推式再结合辗转相除法递归处理即可得到最大公约数和方程的一组正整数特解。

## 四、乘法逆元

乘法逆元是非常重要的概念，特别是在我们计算组合数是，当我们需要在$mod\,p$的条件下除以一个数时，就可以乘以这个数$mod\,p$的乘法逆元。
$a\,mod\,p$有乘法逆元要求$gcd(a,p)=1$，并且对于任意的整数**b**,如果满足$a|b$(**a**能整除**b**)，则存在一个整数**x**，使得$\frac{b}{a}≡bx(mod\,p)$，则称**x**为**a**模**p**的乘法逆元，记为：
$$a^{-1}(mod\,p)$$

## 五、费马小定理求乘法逆元

### 1、欧拉函数：

首先我们需要了解欧拉函数$\phi(m)$，它的值表示从$1~m$的正整数中与**m**互质的数的个数，其公式表达如下：
$$\phi(m)=m\prod\limits_{i=0}^n(1-\frac{1}{p_{i}})$$

### 2、欧拉定理：

接着，我们可以引出欧拉公式，对于任意两个正整数**a**与**n**，若$gcd(a,n)=1$，即存在以下关系：
$$a^{\phi(n)}≡1(mod\,n)$$
特别的，当**n**为质数时，$\phi(n)=n-1$，即只有**n**自己与自己不互质，即一共由$n-1$个数与其互质。

### 3、费马小定理：

最后，我们可以将欧拉公式进行变形得到费马小定理:
$$a^{p-1}≡1(mod\,p)$$
其中，**p**必须为质数，通过费马小定理我们可以进一步推导出一个推广公式：
$$a \times a^{p-2}≡1(mod\,p)$$
我们再对比乘法逆元的表达式可以发现公式中的$a^{p-2}$即为**a**的乘法逆元，我们可以通过快速幂算法快速求得其逆元。

## 六、扩展欧几里得算法求乘法逆元：

我们知道当**p**为质数时，我们可以通过快速幂算法求得逆元，那么当**p**不为质数时怎么办呢？
那么我们就可以通过推广欧几里得算法来求解乘法逆元。
首先我们可以观察求a的乘法逆元公式的表达形式：
$$a \times a^{-1}≡1(mod\,p)$$
可见，可以将此公式进行变形得到：
$$ax-y_{1}p≡1(mod\,p)$$
其中，**x**即为**a**的乘法逆元，而$y_{1}$则为$mod\,p$的一个倍数,我们令$y=y_{1}$可得：
$$ax+py≡1(mod\,p)$$
所以通过扩展欧几里得算法求出的**x**即为**a**的乘法逆元，如果**x**为负数我们只需要通过以下代码即可将其变为正数：
 `x=(x%p+p)%p`

## 七、扩展欧几里得算法示例代码如下：

```C++
#define _CRT_SECURE_NO_WARNINGS
#include <iostream>
#include <algorithm>

using namespace std;

int exgcd(int a, int b, int& x, int& y)
{
	if (!b)
	{
		x = 1, y = 0;//如果b=0，说明x，y只有一组值——1和0
		return a;//由欧几里得算法可知b=0时返回a
	}
	int d = exgcd(b, a % b, x, y);//递归
	int temp = y;//存y的值
	y = x - a / b * y; //按照裴蜀定理变换（a%b）得到y表示的值为（x-a/b*y）
	x = temp;//将原y的值赋给x，由公式变换得到x的值是不变的
	/*
	优化形式
	int d = exgcd(b, a % b, y, x);
	y -= a / b * x;
	*/
	return d;
}

int main()
{
	cin.tie(nullptr);
	ios::sync_with_stdio(false);
    int n;
    cin >> n;

    while (n--)
    {
	  int a, b, x, y;
	  cin >> a >> b;
	  exgcd(a, b, x, y);
	  cout << x << ' ' << y << endl;
    }

  return 0;
}
```
